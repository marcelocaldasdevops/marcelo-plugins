# Vercel Agent Skills ⚡

Coleção oficial de habilidades (skills) da **Vercel** adaptada e empacotada como plugin universal para **Google Antigravity**, **Cursor**, **Claude Code**, **Bithub** e **OpenAI Codex/Cline**.

Baseado no repositório oficial [`vercel-labs/agent-skills`](https://github.com/vercel-labs/agent-skills).

---

## 🛠️ Habilidades Incluídas (9 Skills)

1. **`deploy-to-vercel`**: Deploy e inspeção de projetos na plataforma Vercel.
2. **`vercel-optimize`**: Otimização completa de configurações, cache, rotas e performance Next.js.
3. **`vercel-cli-with-tokens`**: Suporte para autenticação e comandos via Vercel CLI com tokens.
4. **`react-best-practices`**: Boas práticas recomendadas pela Vercel para React e Next.js.
5. **`react-native-skills`**: Padrões e técnicas de alta performance para React Native e Expo.
6. **`react-view-transitions`**: Animações suaves de transição de telas com View Transitions API.
7. **`composition-patterns`**: Padrões de composição de componentes e design system.
8. **`web-design-guidelines`**: Princípios de design web moderno, contraste e acessibilidade.
9. **`writing-guidelines`**: Padrões de escrita técnica e redação de interface.

---

## ⌨️ Comandos Slash
- **`/deploy`**: Inicia o fluxo de deploy na Vercel via skill `deploy-to-vercel`.
- **`/optimize`**: Executa a auditoria de performance e otimização do projeto.

---

## 🚀 Como Instalar

### No Antigravity CLI (`agy`):
```bash
agy plugin install plugins/vercel-agent-skills
```

### No Claude Code:
```text
/plugin install vercel-agent-skills@marcelo-plugins
```

### No Cursor / Bithub:
Ative o plugin `Vercel Agent Skills` na lista de extensões do marketplace.
