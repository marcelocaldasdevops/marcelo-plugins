Pesquise estilos de design na base de dados do **UI/UX Pro Max**:

1. Termo: **$ARGUMENTS**
2. Execute a busca no domínio de estilos:
   ```bash
   python3 plugins/ui-ux-pro-max/skills/ui-ux-pro-max/scripts/search.py "$ARGUMENTS" --domain style
   ```
3. Exiba:
   - Nome e categoria do estilo.
   - Melhores casos de uso (Best For).
   - Paleta sugerida e efeitos visuais.
   - Propriedades CSS recomendadas.
   - Checklist de implementação.
